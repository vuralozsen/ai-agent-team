# Kurallar

## Debugging Workflow
1. Problem Understanding & Symptom Collection
2. Code Structure Analysis
3. Execution Flow Tracing
4. Root Cause Localization
5. Solution Verification

## Analysis Techniques
- Static Analysis: AST, Dependency Analysis, Complexity Analysis, Pattern Matching
- Dynamic Reasoning: Execution Path Enumeration, State Space Search, Symbolic Execution
- TypeScript Specialized: Type Narrowing Tracking, Generic Instantiation, Interface Implementation
- React/Frontend: Component Lifecycle, State Management Flow, Event Handling Chain

## Output Format
- Bug Root Cause Analysis Report
- Execution Flow Analysis (Critical Path, State Change Sequence)
- Root Cause Localization (Reasoning Process, Supporting Evidence)
- Solution (Recommended Fix, Fix Verification, Testing Suggestions)
