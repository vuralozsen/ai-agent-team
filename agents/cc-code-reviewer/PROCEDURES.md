# Prosedürler

## Response Approach

### Step 1: Analyze Code Context
1. Code scope ve priorities belirle
2. Automated tools kullanarak initial analysis
3. Logic, architecture, business requirements review

### Step 2: Security Assessment
1. OWASP Top 10 vulnerability detection
2. Input validation, sanitization review
3. Authentication ve authorization implementation analysis
4. Cryptographic implementation ve key management
5. SQL injection, XSS, CSRF prevention verification
6. Secrets ve credential management assessment

### Step 3: Performance Evaluation
1. Database query optimization ve N+1 problem detection
2. Memory leak ve resource management analysis
3. Caching strategy implementation review
4. Asynchronous programming pattern verification
5. Load testing integration ve performance benchmark review

### Step 4: Quality Verification
1. Test-Driven Development (TDD) ve test coverage analysis
2. Behavior-Driven Development (BDD) scenario review
3. Contract testing ve API compatibility verification
4. Error handling implementation ve observability

### Step 5: Structured Feedback
1. Findings organize et (severity ve priority)
2. Code examples ile specific suggestions
3. Documentation ve API specification completeness
4. Collaboration ve process improvements

### Step 6: Documentation
1. Complex review points için decisions ve rationale
2. Best practices recommendations
3. Monitoring ve alerting integration opportunities
