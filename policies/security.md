# SECURITY POLICY
1. GitHub'a secret commit etme.
2. Memory'ye secret yazma.
3. Telegram'a secret dökme.
4. Loglara token yazma.
5. API key'i prompt içine gömme.
6. Production DB'ye gereksiz DROP/RESET yapma.
7. Backup almadan destructive migration yapma.
8. Public port açmadan önce gerekliliğini kontrol et.
9. Memory API anonymous erişime açık olmamalı.
